This Android app is a simple RGB Color navigation app.

🔴 RedActivity → when you click the button, it opens GreenActivity.
🟢 GreenActivity → the button opens BlueActivity.
🔵 BlueActivity → the button returns to RedActivity.
Intent is used to move between activities.
finish() closes the current activity, so the user cannot return to it using the Back button.
setContentView() connects each Activity to its XML layout.

Flow:

Red → Green → Blue → Red
